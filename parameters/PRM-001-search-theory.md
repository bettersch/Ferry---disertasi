# PRM-001 — Stage 2 theory verification search

Type: search
Stage: 2 — theoretical review
Created: 2026-10-11
Issue: #5

This parameter set adapts the repository theory-development preset to the access actually available in this session. It is a **targeted source-verification search**, not a claim of exhaustive Scopus/Web of Science coverage.

| Parameter | Project value | Rationale |
|---|---|---|
| Grand-theory source | Original JD-R publication (Demerouti et al., 2001) must be read from an accessible copy of the original article | Repository Stage 2 rule |
| Development window | Primarily 2016–2026, with seminal sources exempt | Current theory developments + original theory |
| Platforms actually available | ChatGPT web search over publisher, PubMed, institutional repository, PMC and other indexed web records; Consensus attempted but quota-blocked | Actual access only; no claim of Scopus/WoS execution |
| Candidate theories/positions | JD-R; COR; Organizational Support Theory/POS; organizational-resilience capability/process perspective | Falsification-oriented comparison of prior candidate model |
| Core construct terms | job demands-resources; digital job demands/resources; perceived organizational support; burnout; organizational resilience; multilevel/cross-level | Directly tied to verified phenomenon and candidate constructs |
| Priority sources | Original theory publications; peer-reviewed theory reviews/developments; full-text publisher/OA/author copies where available | Theory provenance and access quality |
| Exclusions | Method popularity, variable-combination novelty, location-only novelty, unverified summaries as primary evidence | Research rigor |
| Output | Source notes in `literature/theory/`; `theory-map.md`; Stage 2 `THR`/theory-`GAP` statements; GRO-02 only if direction is sufficiently supported | Research workflow |
| Coverage limit | No Scopus/Web of Science run was performed in this session; the four prior Ferry matrices remain working artifacts pending provenance audit | Prevent false comprehensive-review claim |
