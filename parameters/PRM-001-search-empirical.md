# PRM-001 — Stage 3 empirical literature search

Status: ACTIVE / WORKING
Date: 2026-10-11
Basis: `research/construct-lock-matrix.md`; `research/problem-architecture-memo.md`; `research/field-problem-evidence-map.md`; verified GRO-02.

## Research purpose
Reconstruct the empirical literature needed to test the current four-domain problem architecture rather than to confirm it: bounded Digital Job Demands (DJD), Perceived Organizational Support (POS), Burnout, and Perceived Organizational Resilience (POR), while retaining mandated rival constructs and alternative causal orderings.

## Search parameters

| Parameter | Project value |
|---|---|
| Databases | Elicit academic corpus for reproducible discovery in the current environment; direct publisher/open-full-text verification where available. Scopus/Web of Science parity remains a later verification requirement because authenticated index access is not available in this run. |
| Priority | Empirical peer-reviewed studies; recent 2021–2026 frontier prioritized; canonical/closest comparators outside window retained with explicit reason. |
| Quartile | Q1–Q3 prioritized when metadata are available; never used as a hard exclusion rule. |
| Languages | English and Indonesian. |
| Population priority | Policing/public safety/high-reliability/emergency/public-sector first; adjacent occupational contexts retained only when mechanism or construct evidence is otherwise sparse. |
| Core construct sets | Digital Job Demands / ICT demands / technostressors / digital overload / technology difficulty; Perceived Organizational Support / organizational support; burnout / exhaustion; Perceived Organizational Resilience / employee-perceived organizational resilience / organizational readiness / agility / adaptive capacity. |
| Rival sets | General workload/operational demands; technology intensity; digital competence mismatch; supervisor/leadership support; objective resources/welfare; fatigue/trauma/distress; readiness/agility/adaptive performance/operational effectiveness/true organizational resilience. |
| Relation sets | DJD→Burnout; POS→Burnout; DJD↔POS where empirically tested; DJD/POS→POR or adjacent adaptation outcomes; Burnout↔POR/adaptation; reverse-direction/common-cause evidence; digitalization→true organizational resilience as a competing positive pathway. |
| Inclusion | Empirical journal article with a clearly identifiable sample/design and direct relevance to at least one locked construct, focal relation, mandatory rival, or falsification pathway. |
| Exclusion | Purely conceptual pieces except canonical theory already registered; dissertations/proceedings when peer-reviewed journal evidence exists; digital-use studies that do not separate exposure from demands/strain; individual resilience studies mislabelled as organizational resilience; articles with no usable result for the Stage 3 architecture. |
| Outputs | Search log with RUN IDs; included-source notes; focused evidence matrix; LIT synthesis statements; GAP/problem statements; GRO-03 recommendation. |

## Epistemic rule
Association findings from cross-sectional/self-report studies are not treated as causal effects. Mediation coefficients are treated as statistical indirect relations unless temporal/identification conditions justify stronger language. Mixed/null evidence remains mixed/null.
