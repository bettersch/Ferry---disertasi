## Critical appraisal
COR provides a useful complementary resource-loss mechanism, but based on the evidence inspected so far it does not add a necessary organizing function beyond JD-R for the candidate demand/resource→burnout process. It should not be stacked as a co-equal grand theory without a distinct explanatory need.
